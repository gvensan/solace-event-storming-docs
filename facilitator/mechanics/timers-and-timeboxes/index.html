Timers and timeboxes

Event Storming is a timeboxed method: you give the room a fixed window per activity (“15 minutes, put up every event you can think of, go”) to force divergence before convergence. The phase timer is the shared, digital version of that stopwatch. It is a single countdown computed identically on every screen, so a distributed room sees the same clock. It is a facilitation cue, never an enforcer.

Turn it on first. The clock is opt-in: tick run this workshop to a clock in Settings, Board. Until you do, the phase timeboxes, the toolbar’s timer controls and the phase stepper stay hidden, because a session you are not running to a clock does not need them on screen - and without the clock there are no phase gates either: voting is always open, and nothing folds. Ticking it starts the agenda at 3 · Storming (the map covered alignment); step back for a formal concept or framing pass. The choice belongs to one workshop and is stored with it: ticking it here does not put a clock on your other workshops, and it follows the workshop to any device or co-facilitator rather than living in one browser. Everything on this page assumes the setting is on.

Set the defaults on the map. Ticking the clock on the Big Picture map shows the same timebox editor the boards have, and the minutes you set there become the defaults for every use-case board in the workshop - decide the schedule once, at the workshop’s home, before the room fans out. A board can still tune its own numbers in its Settings; those edits apply to that board only and leave the map’s defaults standing for its siblings.

Who operates it

Section titled “Who operates it”

Facilitator only. Setting, extending, or clearing a timer rides on the phase change. Participants and observers see the countdown but cannot change it.

Using it

Section titled “Using it”
  • Set a timer by entering minutes when you switch phase. Per-phase defaults pre-fill sensible values (out of the box: 30, 20, 75, 50, and 30 minutes, sized to a four-hour workshop; set the workshop’s own defaults on the map, or tune one board in its Settings, Board, phase timeboxes).
  • Run it like a transport: play ▶ starts the clock, pause ⏸ stops it while remembering the remainder, resume picks it back up, stop ⏹ clears it, and restart ↻ runs the same timebox again.
  • Extend a running timer with “+5 min”.
  • The countdown shows as an mm:ss chip for everyone. On expiry it turns red and counts negative.
  • Clear it by changing phase without a value (or with stop).

There is one active timer per board, tied to the current phase, and it is optional: a phase can run with no timer.

On expiry

Section titled “On expiry”

Hitting zero plays a one-shot chime and opens a “Timebox up” prompt (“The room can keep working - nothing is locked. Extend, or move the agenda along.”). That is all it does. It never auto-advances the phase or locks the board. The timer prompts the human facilitator; it does not act.

Retrospective

Section titled “Retrospective”

Because the timer lives in the event log, playback can show planned-versus-actual duration per phase, a useful “where did the time go” view at the end. See Replay and history.
